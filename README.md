# ETL 2.0

Единая цифровая система учёта электрооборудования, регистрации результатов электрических испытаний, ведения электронных паспортов и формирования технической документации.

## Стартовый комплект

Файл `ETL_2.0_Starter.zip` содержит стартовую структуру каталогов и комплект проектной документации:

- генеральное техническое задание;
- концепцию и предварительную архитектуру;
- модель данных и описание API;
- границы модулей и протокол работы ИИ-агентов;
- доску задач и журнал архитектурных решений;
- открытые вопросы и отчёт о предварительном аудите;
- план тестирования, развёртывания и руководство пользователя.

Архив является документационной основой, а не готовым программным продуктом. Предварительная архитектура требует подтверждения после обследования исходной ETL.

## Принципы работы

1. Не удалять и не заменять существующие функции без анализа и согласования.
2. До массовой разработки провести аудит исходников, данных и образцов документов.
3. Не изменять фактические результаты измерений и не придумывать нормативные критерии.
4. Сохранять оригиналы документов и историю изменений.
5. Все изменения проверять тестами и документировать.
