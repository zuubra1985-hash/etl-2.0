## Принципы проекта

1. Существующую ETL сначала обследовать; не переписывать и не удалять работающие функции без согласования.
2. Все сущности, результаты и документы связывать через устойчивые внутренние идентификаторы.
3. Результаты измерений хранить как фактические данные; нормативную оценку отделять от их записи.
4. Сохранять оригиналы документов, версии и историю исправлений.
5. Не считать задачу выполненной без проверки и документирования.
